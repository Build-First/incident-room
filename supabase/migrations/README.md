## Why it is pasted and not pushed

The Supabase CLI can do this for you, and on a bigger project it should. Here,
pasting once is faster than installing and linking a CLI, and it means you see
the SQL run and the tables appear. Read what you are about to paste. That habit
is worth more than the tooling.
